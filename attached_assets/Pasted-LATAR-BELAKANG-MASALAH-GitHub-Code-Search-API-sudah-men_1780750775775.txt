LATAR BELAKANG MASALAH:
- GitHub Code Search API sudah menghapus fitur sorting by date sejak Maret 2023
- Parameter sort=indexed dan order=desc diabaikan oleh API
- API hanya mengembalikan "best match" yang campuran lama dan baru
- Token GitHub hanya menaikkan rate limit, TIDAK bisa mengembalikan fitur sorting

SOLUSI YANG DIBUTUHKAN:
1. Ganti dari Code Search ke COMMIT SEARCH (masih bisa sorting by date)
2. Tambahkan filter waktu pushed:>2025-05-01 ke setiap query
3. Tambahkan filter kata kunci negatif NOT test NOT example NOT dummy
4. Tambahkan validasi format credential dengan regex sebelum simpan
5. Tambahkan dork crypto spesifik
